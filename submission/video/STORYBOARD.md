## Frame 6 — A Google Cloud architecture with checked AI.

- status: animated
- src: compositions/frames/06-google.html
- duration: 52s
- transition_in: cut
- scene: Official Google Cloud/Firebase icon architecture, focused service highlights one by one. Persistent badge: Implemented integration architecture; live cloud deployment not verified in this recording. Show schema → repair → fallback.
- voiceover: Our connected implementation is designed around Google Cloud and Firebase. Firebase Authentication identifies sessions. The Hono API is packaged for Cloud Run and owns every mutation. Firestore stores shared civic records, and Cloud Storage holds sanitized photos and private voice media. Firebase Hosting is the target for serving the web application. Gemini through Vertex AI assists with transcription, wording, issue categories, duplicate comparison and photo observations. Each AI result is checked against a schema and task rules. One repair is allowed, followed by a deterministic fallback. Application code computes ward assignment, priority, service targets, verification and every public metric. This diagram describes the implemented integrations; live cloud deployment and live model quality are not verified in this recording.
