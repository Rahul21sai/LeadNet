Namma Civic, by Tri-Fusion, is a Bengaluru civic-community prototype that keeps local problems visible from observation to evidence and citizen verification. The public Vercel demo shows fictional issue histories on real ward geography and browser-local community features. The connected backend is implemented for Firebase Authentication, Firestore, Cloud Storage, a Hono API packaged for Cloud Run, and Gemini through Vertex AI; Firebase Hosting is the web-hosting target. Gemini assists with photo observations, transcription and wording. Schema checks, one repair and deterministic fallbacks bound AI, while code determines ward routing, priority, service targets, status transitions and every metric. Google Cloud deployment and live integration verification are planned separately. Demonstration records are not measured city performance.
