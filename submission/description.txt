Namma Civic is a civic-accountability prototype for Bengaluru that separates an official's claimed fix from a citizen-verified outcome. Citizens draft reports from a photo, voice or text, join nearby issues and review evidence. Gemini on Vertex AI assists with classification, duplicate selection and photo observations; code computes wards, priority, SLAs, transitions, citizen quorum and every ledger number. The architecture uses Firebase Hosting and Auth, Firestore records, Firebase Storage for photos, and a Hono API on Cloud Run. Schema checks, one repair retry and deterministic fallbacks bound AI behavior. The demo uses 369 real GBA wards and 200 clearly fictional issue histories. The owner chose to continue locally; cloud deployment and live model evaluation are deferred.
